# AutoClip — Geração de Vídeos Curtos com IA

Este é um projeto pessoal de aprendizado no qual adaptei partes do código do projeto original [AutoClip](https://github.com/artbyjazi/autoclip) para explorar a automação da geração de vídeos curtos com inteligência artificial.

O objetivo é aprender, na prática, como utilizar Python, modelos de linguagem e ferramentas de síntese de voz para automatizar etapas da criação de vídeos.

## Sobre o projeto

O AutoClip está sendo desenvolvido como uma oportunidade de praticar programação e experimentar ferramentas de inteligência artificial aplicadas à produção de conteúdo.

A ideia é automatizar etapas como a criação de roteiros, a geração de narrações e a organização dos arquivos necessários para a produção de vídeos.

## Tecnologias e ferramentas

- **Python:** desenvolvimento de scripts e automação de tarefas.
- **Ollama:** execução local de modelos de linguagem.
- **LLMs (Modelos de Linguagem de Grande Escala):** geração de roteiros e experimentação com inteligência artificial.
- **Edge TTS:** geração de áudio a partir de textos.
- **Git e GitHub:** versionamento e organização do código.

## Como funciona atualmente

O fluxo de geração de conteúdo contempla as seguintes etapas:

1. Informar o tema do vídeo.
2. Gerar um roteiro dividido em cenas utilizando IA.
3. Extrair os textos de narração de cada cena.
4. Gerar arquivos de áudio individuais para as narrações.
5. Organizar os arquivos gerados para utilização na produção dos vídeos.

O fluxo e as funcionalidades podem mudar conforme o desenvolvimento do projeto avança.
